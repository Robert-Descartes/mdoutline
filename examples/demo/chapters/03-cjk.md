# 3 中文排版验证

本手册的默认主题面向中英混排：正文使用衬线字体（宋体族），标题、表头与
封面使用无衬线字体（雅黑族），代码使用等宽字体。

## 3.1 中文表格

| 阶段 | 命令 | 产物 |
|---|---|---|
| 拼接 | `mdoutline build chapters` | 章 → 单个 HTML |
| 打印 | `mdoutline render chapters.html` | HTML → PDF |
| 书签 | `mdoutline bookmarks book.pdf --html book.html` | 写入 PDF 大纲 |

## 3.2 长段引用与行内元素

书签定位不依赖字体与分页：目录里的每个链接在打印时由排版引擎解析为
具体页码，写大纲时直接读回这些链接标注，因此**分页漂移不会让书签指错
页**。行内代码如 `page.pdf()`、删除线~~旧方案~~、以及 [1.1 节](#sec-1-1)
的交叉链接都按预期渲染。
